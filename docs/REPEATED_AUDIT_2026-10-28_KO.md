# 2026-10-28 반복 코드 감사 보고

기존 통과 테스트 외에 데이터 손상·복구 실패를 의도적으로 주입해 6개 반례를 확인하고 수정했다.

1. Creator import/export의 JSON만 비교하여 텍스처·확장 데이터 손상이 감지되지 않던 문제: 본문과 텍스처 섹션을 둘 다 비교, 롤백에도 적용.
2. 정점 수정으로 중립 메시 삼각형이 뒤집혀도 수정 후 정점만을 기준으로 하는 검사를 통과하던 문제: 수정 전후 삼각형 방향을 함께 검사.
3. opacity 파라미터의 999 같은 비정상 값 허용: 알려진 scalar 바인딩으로 제한하고 opacity 범위 검사.
4. INP JSON의 중복 필드가 묵시적으로 덮어쓰기되는 문제: 중복 필드·NaN/Infinity 거부.
5. 중복 삼각형·비정상 공유 모서리 방향·3개 이상 삼각형을 공유하는 비다양체 모서리 감지 추가.

검증 방법: tests/test_adversarial_integrity.py, 기존 테스트 및 Actions의 CI. 실제 Inochi Creator 0.8 바이너리를 실행한 통합 검증이 아니다. 메시의 보수적인 manifold 검사는 실제 프로젝트와 공식 예제로 호환성을 별도 입증해야 한다.

**남은 미검증:** Creator 네이티브 편집 API, 물리·마스크·피벗·조합 변형의 실 렌더, 자동 미적 평가, 독립 파츠 생성 및 전문 수준 리깅 전체 공정. 테스트 통과만으로 완벽성을 주장하지 않는다.

## 세 번째 반례 반복 검증

기존 품질 검사에서 비메시 노드 GUID 충돌, 파라미터 GUID 충돌, malformed children이 조용히 빠지는 현상을 재현했다. 모든 계층 GUID와 파라미터 GUID의 유일성 검사 및 자식 노드 타입 검증을 추가하고, 3개 회귀 테스트로 고정했다. 실기 Creator나 실제 RE:ARCHIVE 모델 검증은 아직 아니다.
