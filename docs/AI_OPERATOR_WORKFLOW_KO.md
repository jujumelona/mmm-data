# AI 작업 흐름 및 남은 구현 범위

AI는 `rig_agent_capabilities`로 사용 가능한 편집 기능을 확인하고, `rig_agent_model_map`에서 정확한 GUID와 소스 해시를 확보한다. `rig_agent_read_target`으로 변경 대상의 현재 값을 읽고 해시·좌표계를 포함한 배치 JSON을 작성한다. `rig_agent_preview_batch`로 원본을 변경하지 않은 상태에서 전체 변형을 검사하고, 통과 시 `rig_agent_save_batch`로 별도의 새 INX/INP 파일에 저장한다. 변형 후에는 다시 모델을 읽어 최신 SHA를 사용한다.

구현된 파일 기반 편집: 정점/UV 수정, 기존 변형 키폼 수정, 비변형 숫자 바인딩 키폼 수정, 노드/파라미터 이름 및 지원 속성 수정, 기존 바인딩을 보존하는 메시 분할. 변경 대상의 GUID·값 해시가 틀리면 거부한다. 모든 작업은 기하 검사와 원본 데이터 보존 검사를 통과해야 한다.

아직 구현하지 않은 Creator 실시간 정점·피벗·물리·마스크 조작과, 원화 분리·전신 리깅·비전 품질 판정은 실제 지원한다고 주장하지 않는다. 본 파일 편집 엔진은 AI 작업의 하부 명령 인터페이스이지 완전 자율 리깅 AI 모델 자체는 아니다.
